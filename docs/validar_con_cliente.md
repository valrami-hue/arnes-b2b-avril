# Información a validar con un cliente antes de una integración real

Esta lista es para una conversación con el cliente; nada de esto se asumió en la demo.

**Servicios y alcance**
- Catálogo real de servicios y qué queda fuera de alcance.
- Zonas o ciudades donde sí operan.
- Tamaños mínimos o máximos que atienden.

**Datos y privacidad**
- Qué datos del prospecto pueden guardarse y por cuánto tiempo (aviso de privacidad, consentimiento).
- Quién tiene acceso al CRM y cómo se borran datos a petición del prospecto.

**Sistemas**
- Qué CRM o herramienta usan hoy y si existe API o solo exportación.
- Permisos formales para conectarse (credenciales de prueba, ambiente de pruebas).

**Proceso comercial**
- Qué campos son realmente obligatorios para que un asesor dé seguimiento.
- Quién aprueba los mensajes antes de enviarse y por qué canal (correo, WhatsApp, teléfono).
- Qué se puede decir sobre precios y qué no (política de cotizaciones).
- Tiempos de respuesta esperados y criterios de urgencia.

**Calidad**
- Ejemplos reales (anonimizados) de solicitudes para probar la clasificación.
- Qué hacer con duplicados y con solicitudes parciales fuera de alcance.
